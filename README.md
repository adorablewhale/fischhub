# FischHub 2.4.0 for Matcha

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/adorablewhale/fischhub/main/fischhub.lua"))()
```

P opens the INSUI menu. Change gameplay keybinds there; they respond only while
Roblox is focused. Non-Hybrid casts click at your current cursor without moving it.
Repeatedly ignored clicks show a HUD/notification warning; keep the cursor over water.
Hybrid mode uses remotes. Auto Fish and Instant Catch are independent controls.

Accept the versioned terms to load. Cloud dashboards and named launch reporting
are optional and separate. The cloud tab provides your private installation key
for https://adorablewhale.world/dashboard. Configure Discord only on the website.
Local mode needs no account. Optional Windows screenshots/focus/clipboard/file
features use the tray EXE available in the website's Account tab, with complete
source-code.txt. Closing its window leaves it in the tray; Quit stops it.

The release renames resolved locals and shuffles encoded blocks. Readable source
is kept in the owner's private repository; client obfuscation is recoverable.
